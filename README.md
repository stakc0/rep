# REP

A direct clone of the WRLD/politic launchpad checkout, packaged as `/rep`.

- Homepage: `/`
- Launch: `/launch`
- Docs: `/docs`
- API reads proxy to the public WRLD API origin so live world data and launch configuration remain functional.

The frontend and visual assets are captured from the public reference site. Private engine infrastructure, signing keys, and backend custody are not included.
